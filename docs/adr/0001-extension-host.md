# ADR 0001：扩展宿主形态（MCP-only，暂不引入子进程插件协议）

- 状态：**已接受**（2026-09-11）
- 关联：差距分析 H21（`docs/oh-my-pi-gap-analysis-2026-09-11.md` §5.1）、H38（用户文档）
- 决策者：Gyre 维护者；记录者：本轮差距修复

## 背景

oh-my-pi 有一套完整的扩展生态入口（`packages/coding-agent/src/extensibility/*`，58 个文件）：
插件包与市场、自定义工具目录、扩展 UI 子协议、以及围绕它们的安装/信任/版本管理。
Gyre 当前**没有**任何等价入口——第三方只能通过配置文件与工作区文件影响行为。

问题：我们要不要自建一套「插件宿主」（子进程 + JSON-RPC 扩展协议），还是把扩展面
完全交给 MCP？

## 决策

**v1 采用 MCP-only 策略**：Gyre 不自建插件宿主，也不提供「进程内加载第三方代码」的入口。
所有扩展能力都必须落在下面这些**已存在、可审计、进程外**的机制上：

| 扩展点 | 载体 | 能做什么 | 代码位置 |
|---|---|---|---|
| MCP server（推荐） | `[mcp.servers.*]` / `mcp.json` / `agent mcp add` | 新增工具、提示词（斜杠命令）、资源；stdio / Streamable HTTP / legacy SSE 三种传输 | `crates/mcp/`、`docs/mcp.md` |
| 自定义斜杠命令 | `.agent/commands/*.md`、`<config_dir>/commands/*.md` | 把常用提示词固化为 `/name` 命令 | `config::discover_commands` |
| Skill | `.agent/skills/*`、`<config_dir>/skills/*`（含 frontmatter 校验） | 可复用的操作手册，按需注入上下文 | `crates/skills/` |
| 命名子代理 | `.agent/agents/*.md` + `task(agent: ...)` | 受限工具面 / 专属提示词的委派角色 | `crates/agent/src/agent_def.rs` |
| Hook | `[[hooks]]`（17 类事件） | 在生命周期节点执行本地命令与决策 | `crates/core/src/hook.rs` |
| 工作区约定 | `AGENTS.md`（含 `@import`）、`SYSTEM.md` | 注入项目规则与系统提示定制 | `crates/config/src/context_files.rs` |

**明确不做**：进程内 `dlopen`/`require` 第三方代码；自建插件市场；扩展 UI 子协议。
理由：进程外机制已经覆盖「加工具 / 加提示词 / 加角色 / 加生命周期动作」四类需求，
而插件宿主会引入信任链、版本兼容、沙箱与崩溃隔离四个长期负担——在缺少真实生态需求
前不应预付这些成本。

## 后果

- 正面：攻击面与维护面不扩大；所有扩展都是可读的配置/文档/子进程，符合「可审计」取向；
  MCP 生态的现成 server 可直接复用。
- 负面：无法做到 omp 那种「深度 UI 扩展」（自定义面板、按键动作、树视图）。
  需要深度 UI 的场景当前只能改前端源码（`web/c5-ui/`）。
- 需要明确的边界：MCP 的**提示词/资源**能力已接入（`/<server>:<prompt>`、`resources/read`），
  但 MCP 无法注册新的**斜杠命令实现**或**宿主 UI**——这是本决策接受的能力上限。

## 何时重新评估（触发条件）

满足**任意两条**即应重开本决策：

1. 出现无法用 MCP 表达的扩展需求（例如需要在 TUI/Web 中新增面板或按键动作），且有 3 个以上独立诉求；
2. 有外部贡献者愿意维护扩展协议与兼容测试；
3. MCP 规范本身提供了宿主 UI/命令注册的标准机制（此时应优先跟随规范，而非自建协议）；
4. 需要在扩展中共享进程内状态（会话树、编辑器缓冲、审批上下文），且 MCP 的
   进程外边界被证明是硬阻塞。

## 备选方案与未采纳理由

- **子进程扩展协议（omp 风格）**：能力最强，但需要设计宿主 API、能力声明、权限模型、
  崩溃恢复与协议版本化——估算 ≥ 20 人日且需要长期兼容承诺。
- **WASM 沙箱插件**：隔离性好，但工具需要文件系统与网络时仍要宿主代授能力，
  等于把上面的设计问题推迟到能力网关，收益不足以抵消复杂度。
- **仅 MCP**：即本决策；以「少一个生态入口」换取「零新增信任面」。
